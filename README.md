# 企业登记管理系统

## 项目概述

一款轻量化企业登记管理小程序，替代人工 Excel 登记，支持员工信息登记、设备领用登记、工单登记三大核心场景，具备数据存储、查询、修改、导出、权限校验功能。

## 系统特点

- **纯 Python 原生开发**：无需第三方框架，可在 Windows/Linux 终端运行
- **数据本地持久化存储**：使用 JSON 文件存储，支持异常崩溃恢复
- **模块化架构**：6 个独立模块，职责清晰，易于维护
- **完整的数据校验**：手机号、身份证号、设备编号合法性校验
- **权限管理**：管理员密码验证，区分普通用户和管理员权限
- **数据导出**：支持导出为 TXT/CSV 格式
- **自动备份**：支持自动备份历史数据

## 文件结构

```
.
├── config.py       # 全局配置文件（路径配置、权限配置、格式校验规则）
├── utils.py        # 工具类模块（数据校验、格式转换、日志记录、异常处理）
├── database.py     # 数据持久化模块（文件读写、JSON 数据解析、备份恢复）
├── validator.py    # 业务校验模块（身份证/手机号/设备编号合法性校验）
├── service.py      # 核心业务逻辑模块（增删改查、统计、导出功能）
├── main.py         # 程序入口（终端交互菜单、路由分发、用户输入接收）
├── test_system.py  # 系统测试脚本
├── data/           # 数据存储目录
│   ├── employees.json   # 员工数据
│   ├── devices.json     # 设备领用数据
│   └── workorders.json  # 工单数据
├── backup/         # 备份存储目录
├── logs/           # 日志存储目录
│   ├── operation.log    # 操作日志
│   └── error.log        # 错误日志
└── export/         # 导出文件目录
```

## 数据格式要求

### 手机号
- 11位数字
- 以1开头，第二位为3-9
- 示例：`13812345678`

### 身份证号
- 18位字符
- 前17位为数字，最后一位可为数字或X
- 符合加权校验算法
- 示例：`110101199001011234`

### 设备编号
- 格式：`DEV-年份-4位流水号`
- 示例：`DEV-2024-0001`

### 工单编号
- 格式：`WO-年月日-4位流水号`
- 示例：`WO-20240317-0001`

### 日期格式
- 格式：`YYYY-MM-DD`
- 示例：`2024-03-17`

## 开发调试日志

### 阶段1：基础架构搭建
- **问题**：f-string 引号嵌套导致语法错误
- **解决方案**：将 f-string 中的单引号改为双引号
- **修改文件**：validator.py 第453行

### 阶段2：数据格式校验
- **问题**：身份证号校验码算法验证
- **解决方案**：实现加权校验算法，支持18位身份证校验
- **修改文件**：validator.py

### 阶段3：数据持久化
- **问题**：JSON 文件编码问题
- **解决方案**：统一使用 UTF-8 编码，CSV 导出使用 UTF-8-SIG 以支持 Excel 打开
- **修改文件**：config.py, utils.py

### 阶段4：跨模块调用
- **问题**：模块间循环引用风险
- **解决方案**：采用单向依赖，配置模块不依赖其他模块，工具模块仅依赖配置模块
- **修改文件**：所有模块

### 阶段5：权限校验
- **问题**：登录失败次数限制
- **解决方案**：实现登录锁定机制，失败3次后锁定5分钟
- **修改文件**：service.py

### 阶段6：边界处理
- **问题**：极端输入导致程序崩溃
- **解决方案**：添加完整的异常捕获，使用装饰器包装函数
- **修改文件**：utils.py

## 安全特性

1. **数据脱敏**：手机号、身份证号在导出时自动脱敏
2. **权限控制**：管理员密码验证，普通用户仅可登记
3. **操作日志**：所有操作自动记录，可追溯修改记录
4. **数据备份**：自动备份机制，防止数据丢失
5. **异常处理**：完整异常捕获，禁止程序直接闪退

## 注意事项

1. **默认密码**：首次使用请修改默认管理员密码（config.py 中的 ADMIN_PASSWORD）
2. **数据备份**：建议定期手动备份数据
3. **编码问题**：确保系统支持 UTF-8 编码
4. **路径问题**：程序使用绝对路径，可在任意目录运行
